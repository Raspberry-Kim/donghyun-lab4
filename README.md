# 동현전 v0.1

동현랭으로 참전하는 턴제 전략 시뮬레이션 게임이다.
동현 시리즈의 다섯 번째 작은 실험이다.

- 모드: 1인 대 컴퓨터만 있다. 네트워크 대전, 2인 대전, 시나리오 모드는 없다.
- 난이도: 보통. 안개(전장의 안개): 없음.
- 지도 4종, 유닛 19종, 지휘관 5명(붉은별 사령부).

## 동현전 출전 규약

| 변수 값 | 뜻 | 범위 |
|---|---|---|
| 1 | 지도 | 1–4 |
| 2 | 나의 지휘관 | 1–5 |
| 3 | 컴퓨터 지휘관 | 1–5 |
| 4 | 선공 | 1 나, 2 컴퓨터 |
| 5 | 시작 자금 | 0–30000 (1000 단위) |
| 7 | 시드 | 정수 |
| 6 | 출전 | 마지막에 둔다 |

`뿡뿡 번호~뿡뿡뿡` 다음 줄에 `뿡뿡 값~뿡뿡뿡`을 출력하는 식으로 쓴다. 6이 없으면 설정 미리보기만 보여 준다.

## 조작

방향키 커서 · X 확인 · Z 취소 · Enter 메뉴(지휘관 능력, 턴 종료, 저장, 불러오기, 항복) · S 다음 유닛 · A 정보 · Shift 사거리. 좁은 화면과 터치 기기에서는 화면 버튼이 나온다.

## 저장과 불러오기

내 차례에 Enter 메뉴에서 저장한다. 브라우저 칸 3개(같은 브라우저에서만 남는다)와 `.dhsave` 파일 내려받기를 고를 수 있다. 불러오기는 같은 메뉴나 첫 화면의 "저장한 판 불러오기"에서 한다. 저장 파일에는 지도 점령 상태, 유닛, 자금, 지휘관 별, 날짜, 차례, 난수 상태가 들어 있어 이어서 같은 판을 둔다.

## 저작물에 관하여

규칙 구조는 패미컴 워즈/어드밴스 워즈 계열 장르를 참고했으나, 닌텐도·인텔리전트 시스템즈의 그림, 이름, 지도, 음악은 쓰지 않았다. 모든 그림·이름·지도·수치표는 새로 만들었다. 이 게임은 닌텐도와 관련이 없다.

